# Week 0: Your Toolkit

A gentle warm-up before the project starts. No ML here, just the four tools we use every week.

[Open the notebook in Colab](https://colab.research.google.com/github/SS3642/How-Machines-Know-and-Find-What-You-Like/blob/main/Week_0_Toolkit/week0_toolkit.ipynb)

## What is inside `week0_toolkit.ipynb`

| Part | Topic | You learn |
|---|---|---|
| 1 | Python basics | Variables, lists, dictionaries, loops, functions |
| 2 | Classes (OOP) | `__init__`, `self`, methods, a `Movie` and a `Friend` class, inheritance |
| 3 | NumPy | Arrays, maths on whole arrays, 2D tables, `axis`, the dot product |
| 4 | pandas | DataFrames, filtering, `groupby`, `merge`, `read_csv`, `pivot_table` |
| 5 | matplotlib | Bar chart, histogram, line plot, scatter plot |
| 6 | Mini challenge | All four tools together |

Each part has a **Try it** exercise. Answers are at the end of the notebook.

## Time

About 3 to 4 hours. Skip any part you already know.
